# settings

시뮬레이터에서 저장한 설정 파일을 모아 두는 폴더입니다.

- **레이아웃 JSON 저장** → `amr_layout.json` 등: 레이아웃 + 파라미터 전체. "JSON 열기"나 캔버스 드래그로 다시 불러올 수 있습니다.
- **기본설정 파일 내보내기** → `default-config.js`: 팀 공용 기본값으로 쓰려면 `js/config/default-config.js`를 이 파일로 교체합니다.

파일 이름에 날짜·조건을 넣어 두면 비교하기 쉽습니다. 예: `2026-11-20_amr3_speed0.3.json`
