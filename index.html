선택 항목

스테이션 연결 (물류 흐름, 선택 사항)

#Load → Unload이론 CT
모든 스테이션/C/V는 Pallet 1개: 도착 → 설정 시간 → 하류 C/V로 이동 (하류가 비었을 때) / AMR Load 대기 / 배출.
명칭은 AMR 기준:
· 제품 공급 (AMR Load): C/V 끝단. 제품 감지 시간 후 Load 가능 (상류 C/V 없으면 그 시간마다 자체 투입)
· 라인 공급 (제품을 받는 C/V, AMR Unload): 비면 → 공급 요청
  C/V로 라인 회수에 연결하면 → 라인 회수로 이송 / 연결 안 하면 → 소진 시간 후 스스로 소진
· 라인 회수 (제품을 회수하는 스테이션, AMR Load): 제품 도착 → 소진 시간 후 소진 → 회수 요청 (상류 C/V 없으면 생산 시간마다 제품 발생)
· AMR 경로에 연결 안 된 라인 공급/회수 블록은 라인 C/V 칸으로 동작
· 라인 공급/회수: 비면 공급 요청 → 가공 → 회수 요청
· 제품 회수 (AMR Unload): 시간 후 회수 C/V로 이동 (하류 없으면 배출)
연결은 선택 사항: 연결된 라인은 연결된 스테이션만 사용. 연결 없는 라인은 연결 없는 제품 공급/회수 중 준비된 곳을 자동 배정.
ACS는 오래된 요청부터, 가장 가까운 대기 AMR을 배차.

AMR 사양

컨베이어 Loading / Unloading 시간 =
이재 시간 = (Pallet 길이 + 여유 거리) ÷ 롤러 속도. 여유 거리는 실측 보정용 (센서 감지 위치, 감속 구간 등).
제품 중량이 Payload를 넘으면 시뮬레이션이 시작되지 않음.

3·5~8. AMR 파라미터

PIO 시퀀스: (L/U)_REQ → TR_REQ → READY → BUSY → COMPLETE. 통신 시간 = 핸드셰이크 합계.

ACS 교통 제어

대기 포지션(◆): 협소 구간 앞에 배치. 도착한 AMR은 앞쪽 설정 개수 노드에 다른 AMR이 있으면 대기 (노드별로 개수 설정).
양방향 구간(스테이션 분기 등)은 끝까지 한 번에 선점해야 진입 → 안에서 마주치지 않음.
서로 기다리는 교착이 생기면 상태줄·AMR 위에 "⚠ 교착" 표시.
AMR은 앞쪽 노드를 N개까지 선점하고, 다른 AMR이 선점한 노드에는 진입하지 않음. 목적지까지 N개 이하로 남으면 끝까지 한 번에 선점해야 진입 (막다른 분기에서 마주침 방지). 대기 시간을 넘기면 우회 경로를 찾음.

4. 충전 (PIO 자동 충전)

충전소 도착: Docking → PIO 충전 시작 → 자동 충전. 출발: PIO 충전 해제 → UnDocking.
배터리는 작업 중에만 소모되고 충전소에서 충전됨. 잔량이 설정값 이하이면 그 값을 넘을 때까지 임무를 받지 않음.

시뮬레이션

생산 → 휴식 반복. 휴식 중 라인 소진·가공 시간은 멈추고, C/V 이송과 AMR 공급/회수 임무는 계속. 휴식 0 = 휴식 없음.
